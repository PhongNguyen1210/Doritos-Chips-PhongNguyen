# Responsive Chips Website

## ❤️ Giới thiệu

- Thiết kế trang web Responsive Chips sử dụng HTML, CSS và JavaScript.
- Bao gồm các hoạt hình khi cuộn trang.
- Cuộn mượt mà ở mỗi phần.
- Phát triển đầu tiên với phương pháp Mobile First, sau đó cho máy tính để bàn.
- Tương thích với tất cả các thiết bị di động và giao diện người dùng đẹp và dễ chịu.
